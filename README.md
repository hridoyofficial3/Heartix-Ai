# Heartix-Ai

ফোনের ভেতরেই চলা একটা বাংলা AI সঙ্গী অ্যাপ (Android)। চ্যাট, স্মৃতি, নোট, ডায়েরি, রিমাইন্ডার, ছবি দেখা, কোড রিভিউ, ওয়েব সার্চ, সব এক অ্যাপে। Telegram বা Termux লাগে না।

## ফিচার
- গাঢ়/হালকা থিমের চ্যাট UI, একাধিক চ্যাট (নতুন, খোঁজা, নাম বদল, মোছা)
- চরিত্রের নাম, ছেলে/মেয়ে, প্রোফাইল ছবি বদলানো
- নিজের API key ম্যানেজার: একাধিক সার্ভিস (Groq, Gemini, Mistral, OpenRouter, OpenAI, DeepSeek, নিজস্ব), লিমিট শেষ হলে নিজে পরের key বা বিকল্প মডেলে যায়
- নোট, ডায়েরি, মুড, টার্গেট, বই, স্বপ্ন, রিমাইন্ডার (নোটিফিকেশনসহ), নিয়ম শেখানো
- ছবি পাঠালে দেখে উত্তর দেওয়া, কোড ফাইল/জিপ রিভিউ ও ঠিক করা জিপ তৈরি
- ওয়েব সার্চ, লিংকের তথ্য, সরাসরি ফাইল ডাউনলোড
- সকালের আবহাওয়াসহ গ্রিটিং, অটো-ডায়েরি, সাপ্তাহিক রিপোর্ট (`অটো বার্তা বন্ধ` লিখলে বন্ধ)

## APK বানানো ও ইনস্টল
1. এই রিপোতে `AgentApp.zip` আর `.github/workflows/build.yml` থাকলে GitHub নিজে বিল্ড করে।
2. **Actions** ট্যাবে "Build APK" রান শেষ হলে **Artifacts → agent-apk** নামাও।
3. জিপ খুলে `.apk` ফাইলটা ফোনে ইনস্টল করো (অজানা সোর্স থেকে ইনস্টলের অনুমতি লাগবে)।
4. অ্যাপ খুলে সেটিংস → API key ম্যানেজার থেকে অন্তত একটা key যোগ করো।

## গোপনীয়তা
- সব ডেটা (চ্যাট, স্মৃতি, key) শুধু তোমার ফোনের ভেতরে থাকে।
- AI-র উত্তরের জন্য মেসেজ তোমার দেওয়া সার্ভিসে (যেমন Groq, Gemini) যায়।
- রিপোতে কোনো API key রাখো না।

## সীমাবদ্ধতা
- ইউটিউব/ফেসবুকের ভিডিও ডাউনলোড এবং PDF পড়া নেই।
- ব্যাকগ্রাউন্ড মেসেজ প্রতি ~১৫ মিনিটের চক্রে আসে; ব্যাটারি সেভারে দেরি হতে পারে। অ্যাপের ব্যাটারি সেটিং "Unrestricted" দিলে ভালো চলে।
